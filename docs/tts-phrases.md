## Як користуватись

Для кожної фрази — 4 поля:

- **Оригінал** — точний текст з `lesson.json` (з emoji, markdown, тощо)
- **TTS input** — те, що реально йде у TTS engine після `clean_for_tts()` (без emoji/dingbats/lапок)
- **❗ Проблема** — коротко: який склад наголошено неправильно (`нЕ` замість `не`, `алмАз` замість `алмаз`, тощо). Порожньо = ще не перевірено.
- **✏️ Виправлення** — виправлений текст. Форми:
  - **Просте переформулювання** — заміни слово/порядок щоб TTS сам поставив правильний наголос
  - **SSML-теги** — `<phoneme alphabet="ipa" ph="...">слово</phoneme>` (для Google/Azure/OpenAI, не Piper)
  - **Плюсик перед голосною** — `алм+аз` (Piper +eSpeak convention, треба verify)
  - **«Ideal»** — якщо треба повністю переформулювати фразу (напр. розбити на дві)

**Порядок роботи:**
1. Оба́хом читаєш блоки, вписуєш «Проблема» + «Виправлення» у файл (можна одним batch, коли послухаєш поточні `.mp3`)
2. Комітиш зміни (це файл — SoT для регенерації)
3. Я запускаю regen тільки для рядків з непорожнім «Виправлення» + новим TTS engine (див. [`tts-systems-inventory.md`](tts-systems-inventory.md))
